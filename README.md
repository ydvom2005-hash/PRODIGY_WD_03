# 🎮 Tic Tac Toe Game (AI Powered)

A modern, interactive **Tic Tac Toe** web application built using **HTML, CSS, and JavaScript**.  
The game supports **2-Player mode** and **Player vs Computer mode** with **Easy, Medium, and Hard AI difficulty levels**, featuring a futuristic neon UI design.

## 🧠 Features

- 🎯 Two Game Modes  
  - 2 Players (Local Multiplayer)  
  - Player vs Computer (AI)

- 🤖 AI Difficulty Levels  
  - Easy – Random moves  
  - Medium – Win & block strategy  
  - Hard – Minimax algorithm (Unbeatable)

- ✨ Modern Neon UI  
  - Glassmorphism design  
  - Neon glow effects  
  - Smooth hover animations

- 🔄 Game Controls  
  - Restart game anytime  
  - Switch modes instantly  
  - Change AI difficulty on the fly  
  - Live game status updates

- 📱 Fully Responsive  
  - Works on desktop, tablet, and mobile devices

## 🧩 Game Logic Overview
- Uses an array to maintain board state
- Dynamically checks win and draw conditions
- AI logic:
- Easy → Random move selection
- Medium → Attempts to win or block opponent
- Hard → Uses Minimax algorithm for optimal play
- Prevents invalid moves
- Displays real-time game status
